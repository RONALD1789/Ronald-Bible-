# RonaldBible

RonaldBible is a comprehensive, offline-ready Scripture reading and study application.

## Features
- **Scripture Reader**: Complete King James Version (KJV) Bible with chapter navigation and parallel NKJV reference links.
- **Verse Commentary**: Verse-by-verse commentary with instant tap-to-reveal context and meanings.
- **Study Tools**:
  - Daily verse & streak tracker
  - Bookmarks, verse highlighting, and personal study notes
  - 7-day guided reading plans
  - Topical Bible study index
  - Scripture cross-reference explorer
  - Bible dictionary
  - Guided observation, interpretation, and application worksheet
  - Private prayer journal
  - Speech synthesis chapter read-aloud
  - Portable JSON backup and restore
  - Dark mode and custom text sizing
